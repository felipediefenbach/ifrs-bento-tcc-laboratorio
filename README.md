# Sistema de Controle de Estoque de Laboratório

## Tecnologias
- Node.js
- Express
- Sequelize (ORM)
- MySQL
- JWT (autenticação)
- Bcrypt (criptografia)
- Express Validator (validações)

## Requisitos
- Node.js 14+
- MySQL 5.7+
- npm ou yarn

## Instalação
- Clone o repositório
- Instale as dependências:
```bash
npm install
